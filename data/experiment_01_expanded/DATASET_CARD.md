# Expanded synthetic evaluation set

This set contains 60 coding-agent-authored English scenarios, reviewed by the same agent for ordinary adult context and absence of identifying information. It was created on 7 November 2026 for Relevia's controlled prompting baseline. It contains no copied archived dialogue, collected user conversation or participant disclosure. There is no human or clinical validation, and no participant consent record is implied for fictional scenarios.

There are ten scenarios per category: learning, work, relationships, everyday constraints, uncertainty, and positive events or explicit preferences. Every row is its own conversation group. All rows are test-only; they must not be used for prompt tuning, few-shot selection, training or early stopping. The original four development and eight pilot test cases remain separate. This is a convenience sample with limited cultural and linguistic diversity, not a representative benchmark.

These are newly generated project materials, not a redistribution under an external dataset licence. No external licence clearance is asserted for EmpatheticDialogues, ESConv or the quarantined archive through this card. Any public dataset release needs the owner's approval and an explicit distribution licence. Local research use is authorised by the project request.

The integrity report documents exact and lexical near-duplicate checks. Such checks do not prove semantic independence or absence from model pretraining. Prompt-aware agent authorship can bias scenario selection. Independent review, multilingual cases, multi-turn response evaluation and realistic deployment sampling remain outstanding.
